# 室内家具布局：CSP × 轻结构 × 饱和效用（“更好而非最优”）

> 目标：在给定房间与若干家具下，找到**合理**（非最优、可接受）的布局解，避免“挤成一团”或“全部贴墙”的极端。

---

## 0. 术语与区域划分

- **墙带（Wall Band）**：距任一墙面 ≤ `d_wall` 的环形区域（建议 `d_wall = 0.25–0.40 m`，含踢脚/走线缓冲）。
- **内域（Interior Band）**：将房间最小外接矩形向内缩 `d_interior`（建议 `0.6–1.0 m`）后得到的中央/半中央带，用于容纳“中岛/核心群”。
- **自由连通区面积 `A_free(L)`**：布局 `L` 在考虑净距膨胀后的**最大连通**可行走区域面积。
- **基线自由区 `A_base`**：两者取大  
  - `A_wall`：沿墙贪心基准布局的自由区  
  - `A_best_so_far`：搜索历程中已知最大自由区  
  ⇒ `A_base = max(A_wall, A_best_so_far)`

---

## 1. 模型分阶段（分析 → 规则 → 衡量）

### 阶段 1｜CSP（硬约束）

**硬约束（必须满足）：**
1. **边界**：所有家具完全位于房间内，尊重门窗保留区/墙面净距。
2. **不重叠**：任意两件家具在净距膨胀后无交叠。
3. **可达性**：从主门到**每件家具**存在路径；路径**最小瓶颈宽度 ≥ 0.60 m**。  
   > 可选：主通道 0.80 m、次通道 0.60 m。
4. **动作原子**：平移（上下左右最小步长 1 cm）、旋转（±90°）。

**问题观察：**  
仅靠 1–3 可生成大量**简单但不理想**的解（成团、通道拥挤、功能感差）。

---

### 阶段 2｜加入单目标（最大化自由区）

- 目标：最大化 `A_free(L)`。
- 风险：以“到墙距离”为启发的 DFS/贪心/A* 容易走向**全贴墙**，多样性差；且若从“沿墙初态”出发，算法缺乏“离墙”的动力。

---

### 阶段 3｜CSP + Utility（效用）＋ 轻结构规则

在**硬约束**基础上，加入**极少量“形态结构”规则**与**分段饱和的效用函数**，让系统拥有：
- 远离“成团”的动力（开阔与反聚集）；
- 不被“全贴墙”支配（配额与内域占位）；
- 基本功能合理（舒适距离带）。

---

## 2. 轻结构规则（半硬约束/弱全局）

> 目的：**不禁止**贴墙，但**限制**其支配性，同时**确保内域存在感**。

- **中岛规则（选择其一即可）：**  
  a) 餐桌不得处于墙带；  
  或 b) 客厅“茶几/地毯核心”必须落在内域。
- **贴墙配额（Quota）**：最多 `K` 件家具允许与墙接触（建议 `K = ceil(N/2)`）。
- **内域最低占位**：至少 `M` 件（通常 1–2 件“大件”）位于内域。

> 这三条能让“沿墙解”仍可行，但不再成为效用最高的稳定点。

---

## 3. Performance Measure（效用函数）

> 若任一硬约束不满足，设 `PM(L) = -∞`（或极小罚分）。

### 3.1 自由区饱和评分 `S_area(L)`

设 `r(L) = A_free(L) / A_base`，采用**分段饱和**（避免“越贴墙越涨分”）：
- 若 `r < 0.60` → `S_area = 0`
- 若 `0.60 ≤ r < 0.80` → `S_area = (r - 0.60) / 0.20`
- 若 `r ≥ 0.80` → `S_area = 1.0`（**完全饱和**）

### 3.2 贴墙配额惩罚 `S_wall(L)`

`S_wall = - α · max(0, W(L) - K)`  
其中 `W(L)` 为贴墙件数；`α` 建议 `0.2–0.5`。

### 3.3 内域占位奖励 `S_interior(L)`

- 若 `I(L) ≥ M` → `S_interior = β0`（建议 `β0 = 0.5`）  
- 若 `I(L) < M` → `S_interior = β0 - β1 · (M - I(L))`（建议 `β1 = 0.5`）

### 3.4 反聚集/间距 `S_disp(L)`

`S_disp = - (1/Z) · Σ_ij [max(0, R_ij - d_ij)]^2`

- `d_ij`：两件家具的最短距离；  
- `R_ij`：类型阈值（大–大 0.9 m，大–小 0.6 m，小–小 0.4 m）。

### 3.5 功能舒适带 `S_func(L)`

对关键配对（沙发–茶几、沙发–电视、床–床头柜等），按“目标距离 ± 带宽”给 Huber 型奖励/轻罚。  
示例：沙发–茶几 0.5 m±0.1 m 内加 `+γ`，轻偏离小罚，远离重罚。

### 3.6 通道品质（可选）`S_corr(L)`

`S_corr = λ_corr · max(0, \bar{w}(L) - 0.60)`  
其中 `\bar{w}(L)` 为门→核心区路径的最小宽度均值或分位数。

### 3.7 对齐/对称（极轻）`S_align(L)`

轻惩与房间主轴（0°/90°）偏离的平均角度。

### 3.8 总效用

PM(L) = w1S_area + w2S_wall + w3S_interior + w4S_disp + w5S_func + w6S_corr + w7*S_align

起步权重：
`w1=1.0, w2=0.6, w3=0.6, w4=0.3, w5=0.5, w6=0.2, w7=0.1`

## 4. 域裁剪与解空间控制

- **候选锚点**（每件 10–60 个）：  
  - 墙带锚点  
  - 角落锚点  
  - 内域锚点（蓝噪声/稀疏网格）  
  - 功能锚点（如沙发面对电视、书桌临窗）
- **放置顺序**：体量最大/约束最多的先放，并做同类对称破缺。

---

## 5. 搜索策略

- **束搜索（Beam 10–30）**：扩展“最受限”的家具，保留若干最优且模式多样的部分解。  
- **或 LNS（大邻域重构）**：从沿墙/中岛/对称模板出发，每轮冻结 70% 家具，重排其余，提升 `PM(L)`。  
- **可随时停止**：得到“更好”的解即可，不追求最优。

---

## 6. 接受/停止规则

当布局 `L` 满足：

1. 硬约束通过；  
2. `S_area(L) = 1`（即 `A_free ≥ 0.80*A_base`）；  
3. 贴墙配额 `W(L) ≤ K` 且内域占位 `I(L) ≥ M`；  
4. 瓶颈宽度 ≥ 0.60 m；  
5. `PM(L)` 提升 ≤ ε（如 0.1）；

→ 接受为“足够好”的输出。  
若有并列，按**更少贴墙 → 功能带更好 → 对齐更好**排序。

---

## 7. 参数起步建议

| 参数 | 建议值 |
|------|---------|
| 网格/采样步长 | 10–20 cm |
| 墙带宽度 `d_wall` | 0.25–0.40 m |
| 内域收缩 `d_interior` | 0.6–1.0 m |
| 通道阈值 | 主 0.80 m / 次 0.60 m |
| 贴墙配额 `K` | ceil(N/2) |
| 内域最低占位 `M` | 1–2 |
| 距离阈值 `R_ij` | 大–大 0.9 m；大–小 0.6 m；小–小 0.4 m |
| 功能带 | 沙发–茶几 0.5±0.1 m；沙发–电视 1.8–3.0 m；床–床头柜 0.05–0.15 m |

---

## 8. 动机解释

- `S_area` **80% 封顶**：贴墙不再持续加分；  
- `S_wall` 与 `S_interior` 形成“轻结构动机”；  
- `S_disp/S_func` 保证布局合理分布、功能距离合适；  
- 结果：**沿墙解可行但不占优**，系统自然生成“有中岛、可通行、功能舒适”的格局。

---

## 9. 最小落地清单

1. 定义房间几何的墙带与内域；  
2. 为家具生成锚点（墙带/内域/功能）；  
3. 检查硬约束：边界、不重叠、可达性、瓶颈宽度≥0.60 m；  
4. 计算各项得分：`S_area`, `S_wall`, `S_interior`, `S_disp`, `S_func`；  
5. 使用束搜索或 LNS 组合锚点，依据接受规则返回“足够好”解。

---

**备注：**  

- “所有自由空间都联通”可弱化为“存在一块最大连通自由区贯通门与核心功能区”。  
- 狭长房型可增设“路径转角惩罚”或“横向回旋点”指标，避免单通道结构。
