# Question

我的基本思路是先把房间的连续几何空间（continuous geometry）根据设定的解析度转换为像素空间（discrete pixel grid）。这样一来：

碰撞检测、通道检查、可达性评估都可以用图像算法（EDT、morphology、skeleton）直接做；

家具的移动与旋转可以转换成在 2D grid 上的搜索动作；

原本复杂的连续优化问题可以变成一个 CSP 或 local search 的离散优化问题。

## Stage 1：强约束（Strong CSP）

- 离散化：将连续房间几何按给定分辨率映射到像素网格，家具动作是离散平移 / 旋转。
- 约束目标：
  - 边界约束：家具占用区域必须完全在房间内。
  - 不重叠 + 安全距：对家具做 clearance 膨胀后仍无重叠。
  - 通道宽度：门到每件家具的可达路径宽度 ≥ 0.6m。
- 当前算法：
  - 约束 1+2 → OverlapCost(L) = 越界面积 + 膨胀后重叠面积；用启发式 CSP / hill climbing 通过平移、旋转压缩 OverlapCost，直到 0。
  - 约束 3 → 在网格上把家具当障碍，用 BFS / flood-fill + morphology/EDT 检查门到家具的可达路径是否满足 0.6m。
- 痛点 / 问题：
  1) 随机初始布局虽易找到合法解，但解缺乏设计感、相似度高；解散重叠后如何继续动以满足通道约束？
  2) 重叠消除后，若通道仍不足，缺少驱动家具继续移动的策略。
  3) 一旦硬约束满足就停止，常出现扎堆、贴墙，没有“美学 / 功能”上的继续优化动力。

## Stage 2：多智能体改进布局

- 想引入多智能体，让家具主动优化，核心目标是最大化可利用空间。
- 人类直觉：床、沙发等往往贴墙 → 容易退化为“怎么贴墙最好”的单调方案，需避免。
- 开放问题：
  1) 怎么把“最大化剩余可利用空间”转成多智能体的有效动作与奖励？
  2) 如何避免策略陷入单一的贴墙解？

## Stage 3：Performance Measure 设定

- 硬约束未满足：`PM(L) = -∞`（或极大罚分）。
- 评分项：
  - `S_area(L)`: 自由区饱和度
  - `S_wall(L)`: 贴墙配额惩罚
  - `S_interior(L)`: 内域占位奖励
  - `S_disp(L)`: 反聚集 / 间距
  - `S_func(L)`: 功能舒适带
  - `S_corr(L)`: 通道品质（可选）
  - `S_align(L)`: 对齐 / 对称（轻权）
- 总效用：`PM(L) = w1*S_area + w2*S_wall + w3*S_interior + w4*S_disp + w5*S_func + w6*S_corr + w7*S_align`
  - 起步权重：`w1=1.0, w2=0.6, w3=0.6, w4=0.3, w5=0.5, w6=0.2, w7=0.1`

## 仍待解的方向

- 多智能体相关方法储备不足。
- 全局优化 / 搜索策略如何选：纯 CSP 解可行性，还是需要显式规划 / 实时推理？
