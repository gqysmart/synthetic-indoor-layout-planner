# 项目目标与规划（更新版）

## 🔄 完整流水线概览

本项目的完整流水线从输入到输出如下：

    输入数据 (room.json / 图像 / 视频)
       │
       ├─ 感知模块 (YOLO / UnrealCV 合成数据) [课程后可选]
       │      └─ 家具检测、深度估计、布局识别
       │
       ├─ 状态建模 (必需)
       │      └─ 房间栅格化、占用图、通道膨胀
       │
       ├─ 搜索与规划 (必需)
       │      └─ A* 算法路径规划，验证可达性
       │
       ├─ 约束满足 (必需)
       │      └─ 碰撞检测、通道宽度规则
       │
       ├─ 强化学习 (必需)
       │      └─ Q-learning 导航 agent，学习更优策略
       │
       ├─ 布局搜索 (可选扩展)
       │      └─ 束搜索 / 模拟退火，自动生成家具摆放方案
       │
       ├─ 评测与指标
       │      └─ 可达率、路径代价、RL 成功率、鲁棒性
       │
       └─ 可视化与交互
              └─ 基础 2D 图示 (必需) → 简单 3D/Web 展示 (可选)

该流水线分为三个层次： 1. **课程必交功能** → 状态建模 + A\* + 约束 +
RL + 2D 可视化\
2. **扩展功能** → YOLO/UnrealCV 感知、布局搜索、3D/Web 可视化\
3. **创业化方向** → 电商接口、自然语言输入、多风格生成、平台化部署

------------------------------------------------------------------------

## 🎯 三大核心目标

这个合成室内布局规划项目服务于三个战略目的：

1.  **学术卓越** - 在 2.5 个月内完成并提交所有课程要求的功能
2.  **作品集建设** - 展示合成数据与鲁棒性实验能力，用于远程工作机会
3.  **创业基础** - 在课程完成后逐步扩展为创业MVP

------------------------------------------------------------------------

## 📚 学术要求对应（阶段1：课程必交）

### 核心课程模块（必须完成）

-   **状态建模** → 房间与家具的基础表示（网格、占用、通道）
-   **搜索与规划** → A\* 算法实现路径规划
-   **约束满足** → 空间约束与碰撞检测
-   **强化学习** → 导航型 Q-learning agent

### 简化实现策略

-   **预训练 YOLO** → 只做推理，不重新训练，减少工作量
-   **2D 可视化** → 使用 matplotlib 完成展示
-   **算法优先** → 优先完成 A\* 与 Q-learning，保证报告和演示有核心结果

### 课程映射表

  项目模块     CS188 要求   实现方式
  ------------ ------------ --------------------
  状态建模     搜索         房间和家具状态表示
  A\*规划      规划         家具摆放路径搜索
  约束满足     约束满足     空间约束和碰撞检测
  RL导航       强化学习     Q-learning agent
  预训练检测   应用/扩展    使用 YOLO 推理

**结果**：在 2.5 个月内交付完整的必修模块，确保课程要求完全满足。

## 💼 作品集建设（阶段2：课程后扩展）

### 技术能力展示

#### **合成数据生成管道**

-   **Unreal Engine + UnrealCV** → 自动化生成虚拟房间
-   **多模态数据输出** → RGB、深度、Mask、标注
-   **随机化策略** → 光照、纹理、材质、相机参数多样化

#### **计算机视觉专长**

-   **YOLO 训练与推理** → 在合成+小规模真实数据上训练
-   **鲁棒性分析** → 加入噪声、模糊、压缩、低光、几何扰动等
-   **跨域泛化** → 评估合成→真实的性能差距

#### **作品集交付物**

-   GitHub 仓库（含代码与报告）
-   演示视频（端到端展示）
-   技术博客（方法论与实验分析）
-   Benchmark 报告（鲁棒性与泛化性能）

## 📈 时间线规划

### 阶段 1：课程必交功能（0 -- 2.5 个月）

-   **第1-2周**：状态建模（房间JSON → 栅格 → 占用图）+ A\* 实现
-   **第3-4周**：约束系统（碰撞检测、通道宽度）+ A\* 集成
-   **第5-6周**：导航 RL (Q-learning)，输出成功率与学习曲线
-   **第7-8周**：调试与集成，可视化与报告初稿
-   **第9-10周**：优化性能与鲁棒性，补充用户界面
-   **第11-12周**：完成课程报告、演示视频、正式提交

### 阶段 2：课程后扩展（12月以后）

-   **第3-4个月**：实现布局搜索（束搜索/模拟退火）、改进可视化（open3d/three.js）
-   **第5-6个月**：接入 UnrealCV，生成合成数据；YOLO 训练与鲁棒性实验
-   **6个月后**：探索自然语言输入、电商接口、MVP 产品化
